A studio of drawings in code

Drawings that move when you do.

Portraits that come apart, gardens that grow as you scroll, and small worlds at the foot of a page. Each is drawn in code as SVG, and each comes with the skill an agent follows to make one like it.

Method

Every mark is code.

A crayon stroke is not one line. It is a sheaf of fine strands that follow one path, each offset across the tip and wandering a little, each with its own weight and pressure. Every strand keeps the moment the hand reached it, so the page can draw it on in the order it was made.

footers/crayon/hand.ts

bouquet.ts

// A stroke is a sheaf of strands along one path.

const hand = new Hand(seed);

hand.stroke(stem, "green", {

width: 10, n: 6,

weight: [1.3, 2.6],

secs: 0.35,

});

hand.fill(petal, "red", { angle: -35 });

hand.line(petal, "maroon", { closed: true });

// Each strand carries its moment: --d, --t.

const svg = hand.take();

Method

Read the page backwards.

The page is written whole, as it will stand. The crew measures it, takes it apart into the work a design team would do, and gives each piece to the nearest free hand: guides first, then frames, words and drawings.

hand.ts

// A hand reaches as a person does:

// a quick throw, then a smaller correction.

await hand.reach(frame);

await hand.press();

await hand.reachPoint(corner, 3, 1.2);

hand.release();

// Keys fall unevenly, slower between words.

await hand.type(headline, write);

// The pen goes where the wax goes down.

await hand.follow(tip, 1 / 60);
